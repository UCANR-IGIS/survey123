# UCSD Corwin Center Visitor Map Survey - Exercise

Use the following settings to create a Survey123 Survey to collect points-of-interest for a visitor map.

## Survey name

UCSD Corwin Center POIs

## Form Title

UCSB Corwin Center Visitors Map

## Form Description

You have been hired by the Corwin Conference Center to create a map for visitors. Please walk around the area and capture points of interest (POI) for new map for conference center visitors.

## 2. Questions

### POI Location

Use a map question. Make it required.

Hint: 

Move the blue marker to the POI location.

## POI Name

Singleline text, required.

Hint:

Give the POI a short name, which will appear in the pop-up window. Max 25 characters.

## Description (max 255 characters)

Multiline text. Optional.

Hint: Enter a description of the POI which will appear in the popup window.

## Category

Single select. Required.

Hint: Select the most appropriate category,  or choose 'Other'.

Choices:

accessibility
beauty
food and drink
history & culture
information
landscaping
public safety
recreation
sustainability
transit
visitor amenity

Allow other: yes

## Notes

Multiline text. Not required.

Hint: Add any additional notes about the POI. These will not appear on the web map.

## Show on map

This should be a hidden question.

yes, no, pending

Select the 'yes' option to make it the default.

Visible: no

## Photo

Image question type.

Hint: 

Take a photo of the POI.
