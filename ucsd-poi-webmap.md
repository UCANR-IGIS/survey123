# UCSD Survey123 Workshop Exercise 2: Create a Web Map

## Step 1: Create the View Layer (Filter)

1. Goto Contents and find the "Corwin Center POIs" Feature layer (hosted) 

2. Select 'Create view layer'
    - Add filter
       - Show on map = yes
    - Fields: POI Name, Description, Category, Category-Other

3. Save the View (append '(public map)' to the name)

4. Open the View details page
    - Settings > Verify that editing is disabled

## Step 2: Create the Web Map

5. Go to the item details page for the View Layer, and select 'Open in Map Viewer'

6. Zoom to the POI layer

7. Edit Style 
    - select the Category Field
    - Style options
    - Pick Icons for (look for the POI symbol library)
        accessibility
        recreation
        food and drink
        public safety
    - Increase the size of the  symbols to 30
